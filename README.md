# Portfolio v2026 — Lucie Freihaut

Personal portfolio rebuild using Astro.

## Stack
- [Astro](https://astro.build) — static site framework
- Tailwind CSS — styling
- Markdown — project content

## Structure
- `src/content/projets/` — project Markdown files
- `src/components/` — reusable components
- `src/layouts/` — Base and Project layouts
- `src/pages/` — site pages

## Getting started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
